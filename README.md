# Pactap Direct development status

This repository hosts a generic dashboard and encrypted status snapshots. Use the HTTPS GitHub Pages site and the shared passphrase. Status data is decrypted in browser memory; locking or refreshing closes access. No passphrase, plaintext project data or source specifications are published.

The browser checks for a published snapshot every 40 seconds and on demand. Reported work and runtime observations retain their own timestamps; fetching never makes old evidence current. GitHub publication and caching may delay newer snapshots. Shared access has no individual revocation; earlier downloaded snapshots cannot be revoked.
